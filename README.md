# Machine Learning Suite: Credit Risk Modelling
A demonstration of several machine learning models applied to a German credit risk dataset.  
Includes prediction results, exploratory data analysis, feature engineering, and overall data overview.  
  
Made using Python (scikit-learn, numpy, pandas, matplotlib, seaborn etc.), Jupyter Notebooks, and Streamlit
